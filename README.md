# Sistema de Gestão - Polo de Tecnologia

Este é o repositório do **Sistema de Gestão Integrada**, uma plataforma desenvolvida para otimizar a administração de polos tecnológicos e instituições de ensino técnico. O sistema centraliza desde o controle diário de alunos até a análise macro de indicadores de desempenho através de painéis gerenciais.

## Funcionalidades Principais

O sistema é dividido em quatro pilares fundamentais:

### 1. Gestão de Alunos e Matrículas
*   Cadastro Completo: Registro de dados pessoais, acadêmicos e técnicos dos estudantes.
*   Organização de Matrículas: Fluxo simplificado para enturmação, trancamento e acompanhamento de status de matrícula.

### 2. Controle de Frequência Diária
*   Check-in Automatizado: Registro diário de presença dos alunos.
*   Histórico de Assiduidade: Relatórios consolidados para identificação precoce de evasão do curso.

### 3. Planejamento Acadêmico
*   Grades Horárias: Criação e visualização dinâmica de horários de aulas e laboratórios.
*   Gestão de Turmas: Organização de turmas e disciplinas.

### 4. Dashboards e Resultados
*   Painéis Gerenciais: Visualização em tempo real de dados de retenção, presença e desempenho.
*   Avaliação de Impacto: Gráficos interativos para tomada de decisão baseada em dados sobre o rendimento das turmas.

##  Tecnologias Utilizadas



*   Front-end: Next.js 
*   Back-end: TypeScript
*   Banco de Dados: PostgreSQL
